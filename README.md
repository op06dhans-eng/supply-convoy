# 補給公路（全班連線版）

課堂手機遊戲：學生兩人一車（駕駛＋射手），把補給送到前線；老師用電腦當敵方指揮所（派無人機、下令砲擊、出動攻擊直升機）。

- 老師（電腦，接投影機）：https://op06dhans-eng.github.io/supply-convoy/
- 學生（手機掃老師畫面上的 QR Code）：https://op06dhans-eng.github.io/supply-convoy/play.html
- 同一台電腦練習連線：https://op06dhans-eng.github.io/supply-convoy/preview.html

出處：直升機模型「Mi-28N Havoc」，作者 Rukh3D，CC 姓名標示 4.0（https://skfb.ly/oKowY）。地面與材質貼圖來自 Poly Haven（CC0）。機砲與子彈音效取自 Pixabay。
